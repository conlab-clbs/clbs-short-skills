# 日本語表現ルール（ショート台本）

**長尺スキル `clbs-youtube-script-pro` を入れている場合は、その `references/japanese_style.md`（全11節・NG/OK例つき）も台本を書く前に読む。** 入れていなくても、このファイルと `scripts/qa_script.py` だけで書ける。
このファイルには、ショートで特に効く要点と、ショートだけの扱いを書く。判定基準は長尺と同じで、「話し手が視聴者と普通に会話するときに、口から出る言い回しか」。
例文はすべて説明用に作った文。

## 1. ショートでも長尺と同じに守るもの

- 文頭のメタコメント（結論から言うと・率直に・ズバリ・想像してみてください）、許可取り（〜させてください）、反語（〜ではありませんか）、「皆さん」【FAIL】
- **「〜ですよ」「〜だよ」「〜ですよね」はむしろ使う**：人が話すときの自然な語尾で、人間らしく聞こえる（「プロフィールのリンクから受け取れるよ。」「これ、意外と知られていないんですよ。」）
- **引用で文を止める倒置をしない**【FAIL】：❌「『毎日投稿が正解』って。」→ ⭕「毎日投稿が正解だと思っている人が多いんです。」
- **体言止め・短い言い切りを並べない**【WARN】：文末は述語で結ぶ
- **同じ語尾を3文続けない**【WARN】：60秒は10〜15文しかないので、同じ語尾が続くとすぐ単調に聞こえる
- 段取りの文（「今日は〜について解説します」「ここでは3つを紹介します」）、予告だけの文（「成功する人には、ある共通点があります。」＋中身）、「大切なのは〜点です」【WARN】
- 和訳調・飾りの言葉・盛り上げの比喩・「あの」・「問いを置く」・画面の作りの説明【WARN】
- `**` 強調囲み・余韻ダッシュ（——）・「カタカナ＋数字」の造語【FAIL／WARN】

## 2. ショートだけの扱い

1. **冒頭2秒フックも述語で終える**。タイトルやカバー文言の型（「〜な人の特徴3選」「1日1分で〜する方法」）は、そのまま声に出すと体言止めになる
   - ❌（音声）「パートナーを不幸にする人の特徴3選。」→ ⭕「パートナーを不幸にする人には、3つの特徴があるんです。」
   - ❌（音声）「1日1分でネイティブ発音を手に入れる方法。」→ ⭕「1日1分で、ネイティブみたいな発音になれるんです。」
   - カバー文言・投稿文（Phase 5）は体言止めでよい
2. **フックの主語を省かない**。冒頭は前の流れが無いので、誰の話か分からないまま始めない
   - ❌「頑張って毎日投稿しているのに、フォロワーが増えない。」→ ⭕「あなたは、毎日投稿しているのにフォロワーが増えないと悩んでいませんか？」
   - 共感の心の声は常体を混ぜてよい（「今日も投稿した。でも、また再生数は伸びない。」）
3. **タメ口でよい**。ショートは「保存して何度も見て」「コメント欄に書いてね」「〜なんだよ」のようにくだけてよい。体言止めだけは避ける
4. **行動の指示は興味づけとCTAだけ**。「保存して何度も見て」「プロフィールのリンクから受け取ってね」はよい。本題の説明の途中で「考えてみてください」「比べてみてください」と指示しない
5. **言い切りの強さ**。ショートは断言が強みだが、資料に無い数字・研究・実績を足して強くしない。権威を出すときは、ヒアリングでもらった研究名・実績だけを使う
6. **詰め込まない**。60秒で言える本題は3〜4ビート。説明を足して文を長くするより、1ビート1文〜2文で言い切る

## 3. 書いた後

- 台本を `shorts/YYYYMMDD_<title>/script.txt` に保存して、次を PASS まで回す（`--strict` は和訳調と言い回しの WARN も FAIL にする）

```bash
python3 <このスキルのフォルダ>/scripts/qa_script.py shorts/YYYYMMDD_<title>/script.txt --role short --strict
```

- `--role short` では、見出しテロップ【テロップ：…】の残存（FAIL）、文中の `<#0.8#>`（WARN）、450字超え（WARN）も見る
- 指摘された文だけを直す。常識破壊の対比（「Aではなく、実はB」）は機械が消したがっても残す
